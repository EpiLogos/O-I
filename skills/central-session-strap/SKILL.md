# Central session strap

## What the start already carries

At SessionStart the harness hook prints `[Central temporal ground]`: the World,
the Project (or the root), today's Day, and this session's own NOW and scratch
place. The hooks open that NOW and close it. Write no handoff or session return
by hand; working files go in the scratch place the start names (or the harness's
own scratchpad). If the start carried none of this, read it back with
`ctrl --json action run central.now.list '{}'` and `central.day.read`.

The register: inside one project's concern → `Work/<Name>` and its
`ProjectCentral/`; cross-project, suite-level or world-keeping → the root
(`Control/**`). Ambiguity resolves toward the project that owns the concern.

## The doors

- `oi` — `oi world`, `oi search`, `oi act [describe|invoke]`, `oi explain`;
  describe an Action before invoking it. Central's entry is
  `ctrl --json action run <action-id> '<JSON>'`; no `project` means the root.
- `ctrl control index` — the law, by statement; read the one your act touches.
- `seat status`, `seat join <workcell> <product>` — env-1/2/3 are the only
  development trees.
