## Content standing

The existing public Explore seed is empty at the pinned base. This branch does not invent remote participants, promote private local worlds, or pretend the complete essay/Bimba corpus has been produced.

The initial collection consists of source-backed **site editions** for the six products and the O:I / Research / Shared Field / Build accounts. Each source section has an exact Scene and source reference. Overview membership follows actual document headings; typography and positions are presentation choices, not inferred QL bindings. Edition revisions are deterministic and source-hash-bound. Generated files live only under `public/data/library/`; source builds do not read personal Central or local browser collections.

The fuller corpus remains its existing native production programme (essay #65 / O:I #65). These prepared editions are not a substitute for its submission boundary. A public build is not a live SpaceTimeDB publication or a deployed-site receipt.

## Human interaction

Home → Library → exact Expression/Scene → selection → Read & sources → overlay/beside/full/detached → same field. Gallery and columns resolve the same subjects. Column Scenes remain on one line with measured capacity and +N reveal. The Library holds the current reader without running its frame loop. Camera, selected subject, Scene, publication revision and source revision remain separate from saved particle state. Reload retains explicit addresses; edition drift and missing Scenes require an explicit choice rather than silent substitution.

The public reader has no import/save/fork/editor actions, private owner reads, session join, model credential or local daemon requirement. JSON exposes the published edition. Source rendering is text-only with safe links, not untrusted HTML execution. Only navigation state uses the reader-specific sessionStorage key; storage denial does not prevent reading. Detached source messages require the actual opened window, same origin and matching Expression/revision.
