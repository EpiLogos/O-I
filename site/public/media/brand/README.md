# O:I visual assets

This directory contains the production vector marks and the visual studies supplied for the public O:I site.

## Production marks

- `oi-mark.svg` — braced `{O:I}` mark used as the primary identity.
- `oi-glyph.svg` — unbraced `O:I` glyph for compact contexts.
- `oi-cube.svg` — isometric O:I cube derived from the supplied cube studies; used as the site icon and secondary mark.

The production marks are background-free SVGs so the site can invert cleanly without raster cut-outs or remote font dependencies.

## Reference studies

`reference/` preserves the supplied visual studies as web-optimised source/reference material. They are not runtime dependencies of the production hero; they remain a visual design corpus from which the production identity can evolve.

The last four reinforce two useful visual directions without forcing them into the production mark yet: a more typographic/monogrammatic identity and a restrained framing/grid language that could become part of projection navigation or object focus states.
