### Stable host/adapter contract for Factory, Technè and Nara consumers

`KernelOp.native_expression` accepts `open {path, expected_revision}`,
`exchange {lease, request}` and `close {lease}`. The source path must be disclosed
by Central and is reread at its exact revision. An
`oi.native-expression-binding/v1` document contains the original native host
`basis` and `field`, plus `presentation.units_per_metre`, `slots_a`, `slots_b`.
Each slot array covers **the full GPU texture, including padding**, with explicit
indices into the native sample array. `retainedTopology()` reports drawn count,
texture dimensions and required slot count; it does not invent a correspondence.
Do not turn the test's repeated sample mapping into a production default.

Executable selection is host-only: absolute `OI_QL_FIELD_HOST_BIN` and
`OI_QL_FIELD_WORKER_BIN`. A frame cannot supply an executable. One kernel manager
admits one native driver; a second driver receives a named ownership refusal.
The same iframe's `host-mode` switch keeps its stage and lease. The shared shell
must reuse that mounted host to preserve seamless cross-arrangement continuation;
creating another iframe is not an alternate license to simulate the same event.
W1 retains that shared-shell writer boundary.

`oi.native-expression/v1` messages are source-window/epoch/lease bound. A late
open is closed; a reply from a released lifetime cannot acquire a new stage or
restart its work. Unknown acknowledgements are never automatically replayed.
Native process teardown owns only its dedicated process group, including pipe-
holding descendants. There is no machine-wide process kill or service restart.

The byte-identical QL `InstrumentSession`, `NativeAudioBinding` and
`RetainedFieldBinding` clients retain their provenance and tests. Native C/Rust/
C++ owns domain calculations, target positions, PCM and sample time. The existing
GPU owns resident particle mechanics; the original application owns its stage,
camera and render loop. Native follow disables the renderer's competing cymatic
and toroidal oscillators. No new numerical integration or audio synthesis is
introduced by this lane.
