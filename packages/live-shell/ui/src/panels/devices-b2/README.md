# devices-b2 — faithful device-panel ports (batch 2)

Visual/interactive ports of twelve real Live 12 device panels, rebuilt
original (no Ableton assets): layout regions, control types and groupings
follow the captured running-app screenshots; every stored parameter in the
live-dynamics table has a control. Controls update local state and display
stored values; persistence wiring lands with the per-device M3 edit API
(each panel carries a corner badge saying exactly that — no prose on the
canvas).

## Layout

- `kit.tsx` — the shared control primitives (knob, menu, segmented,
  switch, fader, readout, section, graph helpers, stored-parameter footer,
  device frame, edit-API badge) and the local device-state hook.
- `styles.ts` — `b2-` classes injected once, shell design tokens only.
- `<device>.tsx` — one module per device port; `index.tsx` registers all
  twelve as `devicesb2.*` panels (right-dock).

## Honesty notes

- All twelve captures were readable; every port follows its capture. The
  capture window (1694x1170) shows each device panel at Live's default
  scale; groupings were cross-checked against the params.rs tables.
- Drift and Wavetable are instruments: injecting them into an audio-track
  set crashed Live once (recovered; crash report generated by Live). The
  two ports were captured from MIDI-track sets instead.
- Values are port-local until the M3 per-device edit API lands; the badge
  in each panel head is the only mention of that on the canvas.
