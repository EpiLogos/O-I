# Bounded ACP candidate material proof

This cross-product acceptance helper consumes an **actual** ACP model result and applies its small arithmetic repair through Workcell's native `HostProcessExecutionProvider`. It is not a model simulator, a shell broker, or a general Python sandbox.

The external commission must authorise one change to a disposable OS-temp fixture containing `pricing.py`. The candidate is an absolute JSON path with exactly one `source` string. That source must define only `inclusive_total(prices, tax_rate)` with one return using bounded arithmetic, `sum(prices)` and optionally bounded-precision `round`. Imports, other calls, attributes, loops, comprehensions, decorators, statements and list multiplication are refused before compilation. The trusted checker exercises real numeric cases, requires the initial function to fail, verifies the actual candidate before replacement, and then reads and exercises the written artifact.

Build with `CARGO_INCREMENTAL=0 cargo build --locked --manifest-path Cargo.toml --bin oi-agency-bounded-acp`. Run the binary with six explicit arguments: `--fixture-root` identifies the canonical temporary fixture directory; `--candidate-json` identifies the actual model result; `--authority-ref` identifies the external commission; `--python` identifies the absolute trusted interpreter path; `--context-json` supplies the retained native required-context manifest; `--context-sha256` binds it to the actual ACP acceptance receipt. No fabricated candidate is supplied by this repository. The caller provides the actual model output and commission. The interpreter is invoked with `-I -B -c` and the exact fixed helper source embedded in the binary, never a shell command. Exact original/candidate SHA256 hashes are bound into the argv. The program refuses overwriting an existing proof; it must not be rerun on a successfully repaired fixture.

The proof first observes denial without material authority, registers a short-lived grant and observes expiry denial, then registers the exact commissioned apply/check operation for 60 seconds and one use. The fixed helper has a five-second alarm. Before the real operation, revoked authority and altered argv are refused as well. Immediately before dispatch, the helper re-observes every required source digest against the exact manifest. After the real operation, replay is refused. Workcell's native output/provenance, before/after hashes, test cases, expiry/replay denials and preservation observation are retained in `fixture-root/workcell-proof.json`.

Material demand identity is derived from the exact context manifest digest, so separate commissioned contexts do not collide merely because they use this same helper. This identity fix follows the first two live receipts, whose material identifiers were only locally scoped; their immutable historical records remain unchanged. A native real-filesystem/allocation regression checks distinct contexts and changed-source refusal.

The external authority reference is attribution to the existing commission, not authority manufactured by this helper or by a validator. Material execution uses a trusted, narrow helper on the ordinary host. It does not establish generic process isolation, containment of arbitrary Python, persistent grant accounting across runs, or an unrestricted provider deadline. The helper bounds its own execution, and the test fixture is exclusive temporary work.
