## 3. One positive architecture

The coherent shape is **persistent authored ground, selectively resolved practice, situated attributable agency, actual material execution, developmental work where commissioned, and Return into the appropriate existing source/receiving relationship**. It is not six mandatory services chained in a pipeline. A person's external harness and existing heterogeneous World can participate usefully without Factory or the Desktop. The hosted Library encounter is a browser experience; the visitor does not inherit the host's installation duties.

### C01 — Native offices and legitimate composition

**Authority → relationship.** [Founding Positions][founding] and [harness-first §§1–3][harness] distinguish native responsibilities while requiring useful joined activity. Central keeps persistent human/Project ground and source standing. Actuation constitutes situated Agency, delegated authority, actual activity and Return. AIKit discovers and resolves context/practice/model/harness participation and projects through supported adapters. Factory holds commissioned development, its subjects, attempts, evidence and developmental decisions. Workcell materialises and observes bounded execution conditions, places, processes and providers. O:I provides the coherent doorway, composition, shared interaction and explanation. Native SDKs and connectors accommodate existing foreign identities; O:I need not become their replacement owner.

**Current implementation → findings.** Real native owner CLIs, O:I routing, AIKit's shared application service, Factory owner clients and Workcell material contracts implement substantial parts of this division. The breaks are specific: AI-001's former receiving command; OI-004/FA-005's build-view joins; AI-005's retired Actuation correlation call; CT-001's stale temporal Action names. These do not justify a new central orchestrator or duplicated owner databases.

**Required proof.** A native operation called through CLI, structured agent use, TUI and the intended desktop receiver must preserve its subject, scope, authority, effect and failure meaning. Pixels need not match. Missing optional owners must not prevent unrelated useful work. ALIGNMENT packets P01, P05, P07 and P08 carry the affected joins.
