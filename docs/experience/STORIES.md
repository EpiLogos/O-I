# Stories of useful work

**Owner: O:I #65. Standing: source-grounded intended-experience elaboration under the user's campaign commission; specified, not executed or human-validated.** Read the common source/authority rules in [README](README.md), the compatible record form in [STORY-PROFILE](STORY-PROFILE.md), and P01–P18 in [PRACTICE-CONDITIONS](PRACTICE-CONDITIONS.md). P references supply shared practice obligations; each row supplies their concrete determining conditions. They do not stand for installed Skills.

These are child stories grouped by actual activities, not product screens. Each has its own starting material, human act, agent work, observable result and failure/re-entry. At execution bind actual source/capability/Skill IDs and evidence to the row rather than changing its meaning to match the implementation. Intended outcome is not a script of clicks or an expected sentence to teach the tested agent. The full exact document/QL sources outrank the compact examples here.

The stable ID is a row locator and may become the existing UX `id`; the family is its `parent_ref`. All families map to #65 A–I and existing domain acceptance in the campaign manifest. Context omitted from a compact row inherits the explicitly scoped common packet, never ambient private access.
