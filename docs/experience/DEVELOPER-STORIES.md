## Meaningful combinations, not every possible Cartesian product

The required mixed-world TE05 specimen is simultaneous, not five unrelated green unit tests. Herdr, tmux and cmux each receive their own real-provider episode at the capabilities and host they actually support; one cannot certify the others. The full gateway path GW02 is completed before a simple connectivity result can be described as the gateway experience; richer group/remote/SDK cases remain required at their declared scope.

Use equivalence classes and a documented risk-based pairwise selection for additional combinations. Expand whenever an owner source, specific incident or distinct guarantee requires it. Unselected products and unsupported platforms remain explicit variants/deferrals, not omissions from the parent. Required production joins must be fixed by their owners, not simulated by the test supervisor.

Every new row starts specified. The selected episode adds actual native refs, source revisions, effective Skills/context, grants, machine/terminal/client versions, test tools, independent witness, observable before/after and allowed cleanup. Human EX is supplied only by the person. The same three roles can be enough for a small test; don't create permanent agents or a second campaign runtime for each row.
