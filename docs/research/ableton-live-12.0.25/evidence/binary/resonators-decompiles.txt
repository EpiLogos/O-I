// ===== Init FUN_10199d058 (shared slot recompute; inlined into
// OnResMode/OnResDecay/OnResConst/OnResColor) — key facts =====
// input-filter biquad build (coeffs this+0x36c..0x380):
//   w = min(1/sr * 188.49556, 3.1101768);   // 2*pi*30 / sr, capped below Nyquist
//   sincosf -> sin/cos; alpha = sin/0.2 (Q = 0.1)
//   RBJ highpass-form coefficients, normalized by 1/(1+alpha)
// allpass bank this+0x100..0x114 (6 coeffs): w = min(fLUT*2pi*  (this+0x128),
//   3.1101768), Q = 0.3 (sin/0.6), RBJ form
// pitch -> frequency law (per slot values read at 0x408/0x40c/0x3f4):
//   note_eff = note + cents*0.01 + 24 + (111 - note) * (color*0.75 + 24)*0.01
//   idx      = note_eff*5 + 1381.8816        // 5 LUT steps per semitone
//   f        = LUT0x1059a89a8[idx] + LUT0x1059a89b0[idx]*frac(idx)
//              (runtime-built table, 0x960/4 = 2400 float entries; value above
//               the table clamps to last entry)          // corpus material
// delay-line tuning with allpass phase compensation:
//   phase = atan2f((a*d - b*c)/den, (c*d + a*b)/den)   // complex allpass phase
//   delay_samples(this+0xb8) = sr_ms * 1000/(f - f*phase/-2pi)
//   smoothing: if old == 0 -> jump, else 100-step ramp (this+0xc4 = 100,
//   this+0xcc = (new-old)/100)
// decay coefficient this+0xb4 = (2*decay-1) * (1 - 1/(<shape>^2*5e-05*<fq>+1))
//   with decay = this+0x3ec; the <shape> leg = 0.5 - this+0x3f8*0.5 when
//   this+0x3f0 == 1.0 else sqrt(f)*12 (ResConst branch)   // see dossier
// this+0xbc = this+0x410 * 0.5   (slot gain * 0.5)

// ===== Reset FUN_10199d2b8 =====
// zeroes per-slot filter states (0x348..0x390), delay/allpass states
// (0x118/0x120, 0x198/0x1a0, ...), decay state 0xb4 = 0, gain-hold 0xbc = 1.0f,
// delay read state 0xc8/0xc0, per-slot state resets FUN_1016d3ab0(0xd0/0x150/...).

// ===== CalcMainWithReset (0x1019acb98) — active-slot list build =====
//   tick callback table invoked at *(this+0x3c8); countdown this+0x3d4
//   slots ON flags (stored as 1.0/0.0 floats): slot1 0x404, slot2 0x414,
//     slot3 0x424, slot4 0x434, slot5 0x444
//   active slots appended to a tick list at this+0x30..0x90, entries
//     {slot*, bufA*, bufB*}: slot1 -> 0xb0 with bufs 0x3a8/0x3b0 (L pair),
//     slot2 -> 0x130 with bufs 0x3ac/0x3b4 (R pair), slot3 -> 0x1b0 (L bufs),
//     slot4 -> 0x230 (R bufs), slot5 -> 0x2b0 (L bufs)
//   ALTERNATING L/R buffer pairing per slot (ping-pong band placement)
//   final dispatch select: uVar9 = (uint)(InFilterOn(0x3dc) == 1.0) — one axis
//   of the CalcIn{0,1}Res{0,1}Mono{0..4} selection

// ===== CalcIn0Res0Mono0 (0x1019ac184) — per-sample tick shape =====
//   stereo DF1 biquad on inputs (*(0x98), *(0xa0)) with coeffs 0x36c..0x382,
//     states L 0x388/0x38c/0x390, R 0x398/0x39c/0x3a0  (the In filter)
//   results -> 0x3a8 (L) / 0x3ac (R); 0x3b0 pair = 0
//   Mono0 = no active extra slots: out = width-matrix of dry only:
//     0xa8 = 0x3c0*0 + 0x3b8*inL; 0xac = ... (dry gain 0x3b8, width 0x3c0/0x3c4)
// ===== CalcIn0Res0Mono4 (0x1019ac4a8) =====
//   same input biquad, then 4 slot ticks: func_0x00010199e6bc(entry0..3) with
//   entries {slot, bufA, bufB} from 0x30..0x90
//   out L = 0x3b4*0x3c4 + 0x3c0*0x3b0 + 0x3b8*inL  (wet cross-pan + dry)
