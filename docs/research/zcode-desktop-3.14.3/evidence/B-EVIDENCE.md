## Limitations

- **Depth:** ~60 files read closely of ~700 source files (cradle) + design system. Files in
  `src/encounter/`, `src/configuration/`, `src/agency/`, `src/contributions/factory/`,
  `src/expressions*`, `src/techne/`, `src/nara/`, `kernel/` modules other than git/routine were
  read only at header/grep level. Maturity calls for chat/terminal/diff/layout rest on the
  primary components plus test presence; edge behaviour inside those components was not
  exhaustively read.
- **Absence claims** ("no runtime plugin loader", "no git write ops", "no terminal session
  picker") are negative claims over the areas searched (op union, contributions tree, terminal
  surface), not a proof over every file.
- **Run-state:** I did not build or run the app; `dist/` exists and `node_modules` is installed,
  and `package.json` test scripts imply the suites run, but I have no execution evidence of
  green tests. Maturity judgments are code-and-test-presence judgments.
- `walk/` harness mechanics and `docs/` design docs (`DOCUMENT-SURFACE.md`,
  `THEME-LIBRARY.md`, `docs/experience/*`) were listed but not read; they may hold further
  acceptance law relevant at convergence.
