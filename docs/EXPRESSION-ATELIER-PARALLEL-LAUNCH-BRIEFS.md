# Expression Atelier Programme — Parallel Launch Briefs

**Standing:** operational launch sheet, 16 September 2026.  
**Authority:** subordinate to `docs/EXPRESSION-ATELIER-SUITE-EXECUTION-LOCK.md`, `.wayfinder/maps/expression-atelier-suite.md`, and each native repository's own issue/docs/AGENTS rules.  
**Purpose:** provide paste-ready session briefs for the immediate parallel streams without restating or altering their architecture.

---

## 0. Common rule for every launch

Every session must:

1. work from the **actual current `main`** of its native repository unless an existing coordinated branch is already authoritative;
2. read the native issue and the docs/maps named in its brief before editing;
3. inspect current implementation before assuming a planned seam is absent;
4. preserve native owner boundaries;
5. run the real affected tests/evidence available to that repository;
6. distinguish implementation fact from planned/gated work;
7. return an exact handoff: base/head, files changed, contracts consumed, what is materially true, tests/evidence, degradation/debt, cross-product pressure, next executable step.

A worker encountering a missing foreign seam records and routes it; it does not create a local shadow implementation merely to complete its lane.
