The seven laws

These are the rules that kept being lost between rebuilds. Every state below follows from them.

  1. 1One frame, changing body.The left head (scope, search, create) and foot (Inbox, modes, Settings) never move. Only the body changes with the mode, and every body uses the same row grammar.
  2. 2One conversation, one place.A session appears once, with one composer and one draft. Choosing it again focuses it; moving it carries the draft.
  3. 3State lives on the thing.Working, needs-you, unread and failed are marks on the row, avatar or tab. No banners, no trays, and the layout never moves.
  4. 4Status → Preview → Takeover.A dot, then the live Activity tape, then full-screen chat (⌘⌥J). You choose the depth; nothing escalates by itself.
  5. 5Inspect is a drawer.It opens over the current tab with Back, never as a tab of its own.
  6. 6Headers only above real rows.Empty sections take no space. A failed read says so and offers Retry; it never looks like "empty".
  7. 7Nothing reads like a log file.No "returns", no raw JSON outside Show raw, no scrollbars, no "Situated in…" sentences, no fake rosters.

Anatomy

Left: head · body · foot

Scope ▾ replaces the hardcoded "My O:I" heading. Its menu lists Central, then every project with live marks (● 2 working, ! 1 needs you), then remote machines. A dot on the chevron means another project has news. This one control is both the project picker and the per-project activity overview.

⌕ opens the ⌘K palette (no permanent search field). + is the one create menu: New chat, New flow, plus the mode's own (New run, New Expression, New agent).

Inbox is the single queue of material waiting for you, reachable from every mode. Modes: Base · Factory · Expressions · Technè · Epi-Logos | Settings.

Right: identity · tabs · body · composer

The agent's name is a control. It switches between agents in the current scope, drawn from real AIKit profiles, and replaces "Agent / Situated in Central". A presence dot sits beside it; ⤢ is full screen and ✕ collapses the panel.

At most four text tabs, never a "More" menu. A tab carries a dot for new activity or ! when something needs you.

A status line shows only while a turn runs. The composer carries To: chips, Insert context, the microphone, the model chip for this agent's harness, and Send, which becomes Stop.

What changes from today

Repair first — these are regressions or dead ends

  1. Technè's left body is the wiki map again. Main still mounts the Expressions graph there. The fix (PR #470) was closed on the claim that main already had it, and main does not.
  2. Factory Tasks rows open in the centre. Today they land in the right panel's hidden tab group.
  3. Epi-Logos becomes reachable. The mode switch refuses it today.
  4. Activity becomes reachable. It is built but offered by no mode.
  5. Inspect stops printing JSON.

Removed

Factory Returns / Now / Remembered bands; the "PROVIDER — Bind a conversation to pick" pill; "Situated in Central"; the duplicate New chat; standing New Agent / New Team buttons; the hardcoded Guardians and Ta-Onta lists; the Nara·Anima and Epii tabs (they become agents in the name menu); the footer's duplicate mode radios; the unused legacy right-panel fallback; the "System" vs "Settings" split.

Decisions for you

Everything else follows rulings you have already made. These six are new positions or settle conflicts between rulings.

D1Inspect becomes a drawer in every mode, not a tab.yes: one grammar; it extends your Factory ruling.#375 §2 kept Inspect as a tab in ordinary modes.
D2Epi-Logos becomes the fifth mode in the switcher.yes, replacing the footer toggle.It is in your mode list but cannot be reached.
D3Inbox sits in the fixed foot, in every mode.yes: the queue is app-wide.The 21 Sep spec placed it only in Factory.
D4Outside Factory, a chat row opens in the right panel.yes, with Open in centre as an explicit move.Today it opens a centre tab and can duplicate the right chat.
D5Factory keeps FILES.keep it, collapsed by default.You said on 18 Sep it wasn't needed; the 21 Sep spec kept it.
D6The scope selector is the one place to choose the project.yes: it drives the left body and the right's agent list.Today Factory has its own project select and base has none.
