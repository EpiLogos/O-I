# O:I Expression Field — living presentation of an inhabited world

**Standing:** owner-approved product/design direction, 14 September 2026. This extends the existing Cradle, Personal Web, WorldPresentation, Wiki and Epi/Nara work; it is not a new product, semantic owner, CMS, graph store or particle ontology.

## 1. Product meaning

O:I needs a human and Agent medium in which a world can become directly sensible without being flattened into dashboards, labels or disconnected specialist applications.

The **Expression Field** is that medium.

An Expression is a living presentation of native subjects and relations. It can be quiet and page-like, spatial and graphical, animated and musical, or a full-screen processual instrument. It does not acquire ownership of what it presents. Sources, Wiki subjects, Agents, M coordinates, Nara states, Actions, authority and SharedField identities remain owned by their native systems.

The governing relation is:

```text
native World / source / Wiki / Agent / M-coordinate / activity
                         ↓
                 stable refs + readings
                 relations + Actions
                         ↓
                   EXPRESSION FIELD
            living sensory/presentational whole
                         ↓
        desktop · HTML/page · WorldPresentation · SharedField
```

This makes a stronger claim than "particle renderer" while retaining the renderer's proper office. The point-cloud engine is the current primary material body of Expressions. The Expression Field is the application/composition relation around that body: subjects, scenes, entities, sources, Actions, views, captures, page bindings, agent operations and projections.

## 2. The world is primary; apparatus is summoned

The resting experience is the Expression itself. The person is *in* the presented world.

Graph/search, source/provenance, Epii/Agent conversation, Studio authoring, Context, Activity and other instruments are summonable apertures over that same subject. They are not compulsory permanent sidebars.

```text
REST
┌─────────────────────────────────────────────┐
│                                             │
│              living Expression              │
│                                             │
└─────────────────────────────────────────────┘

summon source / graph        summon Agent / Epii
summon Studio                summon explanation / evidence
```

A side aperture can expand, float, split, detach or become full depth through existing Surface mechanics. Closing it returns to the same Expression, subject and state. Incoming activity never moves the layout by itself.

The current Expressions workspace establishes the desired application idiom: canvas first; direct manipulation; restrained persistent tools; Studio for depth; named scenes; Library; automation; optional text; capture/export. Preserve and refine that idiom rather than reducing the engine to a dumb canvas embedded in a conventional desktop panel system.

## 3. Expressions contain Beings and Things

The Personal Web's canonical families **Beings** and **Things** extend naturally into Expressions.

A **Being** is a presented situated presence: human Participant, Agent/Epii, Nara or another presence whose identity remains native to its owner. A **Thing** is a presented subject: concept, M/Bimba coordinate, source, file, Project, artifact, clock constituent, Wiki subject, oracle object, collection or other addressable object.

An Expression may contain either or both. These are presentation roles, not new identity classes.

```text
ExpressionEntityBinding {
  expression_entity_ref
  subject_ref
  presentation_role: Being | Thing
  source/revision refs
  current owner Reading(s)
  relation bindings
  disclosed ActionRefs
  local presentation/material state
}
```

A Being can become a Thing for another encounter without minting another person or Agent identity. A Thing can lead to its creator, steward, participant or Agent through actual typed relations rather than inferred presentation proximity.

## 4. Every page can be a state of the whole

A Bimba/M coordinate is not reduced to "its page". Instead, it determines a locus from which the same whole can be expressed.

```text
coordinate / subject
        ↓ determines a locus
same articulated world
        ↓ composed from that locus
Expression
        ↓
page · scene · performance · explanation
```

An M2 coordinate foregrounds resonance, material, symbolic and correspondential relations while M1 carrier, M3 form, M4 reception, M0 source and M5/Epii remain available. An M1 coordinate foregrounds topology/harmonics without creating an isolated topology app. An M3 clock constituent can be opened while the same event, source, selection and Nara remain continuous.

Derived coordinate Expressions should be generated from current source/readings and a presentation grammar. They are not 1,875 hand-maintained files. Authored Expressions may refine, teach or artistically present a coordinate and retain exact source revisions.

```text
DERIVED EXPRESSION
coordinate + current readings + presentation grammar

AUTHORED EXPRESSION
human/Epii composition + source/revision provenance
```

## 5. Wiki and knowledge become inhabitable

The Wiki/M0 field is ultimately projectable into the Expression Field.

Any bounded Wiki/knowledge reading can supply a local whole:

```text
source / Wiki / Bimba / filesystem / ProjectMap / query
                         ↓
                 bounded typed local whole
                         ↓
          layout / constellation / harmonic grammar
                         ↓
                     Expression
```

Canonical knowledge identity stays outside the renderer. A graph-projection adapter maps stable subject/relation refs into expressive entities and connective forms. Changing the data query or selected locus changes the projected field without creating another graph database or Expression-owned relation model.

QL pair/triad/whole constellations, harmonics, lenses and source-backed glyph structures can provide stable patterned presentation grammars. They are layout/intelligence inputs, not visual proofs of semantic truth.

A graph view may therefore become a living spatial reading of the same local whole:

- selected subject as the principal locus;
- typed neighbours as related centres/forms;
- relation identities as connective geometry/trajectory/constraint;
- standing/provenance as inspectable presentation treatment;
- click/focus as re-centre/open rather than identity mutation;
- Actions and source/properties available from the same selected ref.

LIST, TREE, GRAPH, page and Expression remain alternative presentations over the same knowledge state.

## 6. Agents are native inhabitants of Expressions

Agents are not chat bubbles attached to the field. They are Beings capable of perceiving and operating the same Expression through structured state and Actions.

An Agent-facing Expression contract must expose, without DOM/canvas scraping:

- Expression / scene / entity refs and revisions;
- bound native subject/source refs;
- current selection/focus;
- Being/Thing role;
- relations and presentation grammar;
- available representations and captures;
- current parameter/automation state where disclosed;
- canonical ActionRefs and authority requirements;
- source-return / publication owners;
- degradation/unavailability.

The human's pointer operations and the Agent's structured operations address the same application meaning.

Representative application operations include:

```text
open/create/fork Expression
bind/unbind canonical subject
project bounded knowledge whole
add/remove/focus expressive entity
bind/update relation presentation
apply known layout / QL constellation
compose/reorder scene
bind live domain state
set/automate permitted parameter
capture image/video
embed into page
save/export
project/publish
inspect source/provenance
invoke selected subject Action
```

These are application operations over existing owners. They do not grant source mutation, Agent authority or publication rights by themselves.

Agent personality/presence may shape presentation, but personality is not authority or identity. Activity may alter visible rhythm/form where deliberately bound; decorative animation must never be presented as evidence that an Agent acted.

## 7. Nara and the M′ instrumentarium

Nara is the richest personal composition of the Expression Field, not the definition of Expressions.

K10 supplies protected Nara/M4 truth. K8 supplies accepted M1/M2/M3 continuous and audio state. O:I owns the Expression Stage/material renderer. The full Nara mode binds those truths into the current engine without creating a second clock, field, resonator, audio owner or personal state store.

The seven Nara centres are **receiving loci**. Cymatic resonant stations are **conditions of the shared resonant medium**. They may be related but must not be identified.

```text
M1 topology/harmonic carrier
             +
M2 resonance/music/material
             +
M3 form/clock/articulation
             ↓
K10 Nara seven independent centres
             ↓
Expression materialisation
```

In the Nara composition:

- M1 can foreground topology, winding, phase, harmonic/carrier relations through the same field;
- M2 can foreground resonance, cymatics, material, colour, music and native audio;
- M3 can foreground glyph, form, transcription and clock structures;
- M4 exposes the independently constituted personal field, activity and all six M4 branches;
- M0 opens actual Bimba/source/knowledge ground;
- M5 is canonical Epii, investigating, operating, teaching and returning.

Selection is inspection. Deliberate Actions change domain or source state. Manual/general Expression authoring controls may coexist with bound domain state only where ownership and override/follow state are explicit.

Portable Nara Expressions contain safe refs/cues and host artifacts, not raw journal, identity, bioquaternion or seven-centre private state. Authorised live personal values are session-local rendering inputs.

## 8. M4.5 / Epii pedagogy

Expressions give the existing M4.5 offices a direct human surface.

Epii can teach by composing and operating Expressions, not merely by narrating them in chat. A pedagogical act can arrange source-bearing Things, foreground a relation, move through several whole-field scenes, attach concise text, expose its method and invite the person to inspect source or perform an Action.

Examples:

- assemble → explode → reassemble the M3 clock with stable constituents;
- enact `0→1` as `/` while source/explanation remains available;
- compare two QL constellation readings over the same knowledge subject;
- show how one M2 condition is differently received by two protected Naras;
- move from a Bimba relation to its M1/M2/M3/M4 determinations without leaving the same presented world.

The right-hand Epii aperture is therefore the conversational/directorial control surface, not the pedagogy itself. M4.5 remains Nara's internal pedagogical/integration office; M5/Epii remains the wider agent/interlocutor.

## 9. HTML, Personal Web and WorldPresentation

Expressions do not replace HTML/page forms. They become a first-class presentational body that those forms can contain.

A Beings or Things page may contain text, links, source readings, a live Expression, image/video captures, related Beings/Things and disclosed Actions. Flow, Day, Cube and Epi-Card can embed live or captured Expressions where appropriate.

`WorldPresentation` remains the portable authored page/world composition above individual renderers. Expression becomes one admitted Component/Surface renderer with explicit fallback:

```text
WorldPresentation
  ├─ heading/text/wiki/card/cube/other components
  └─ Expression binding
       ├─ live accepted renderer when available
       ├─ image/video/frozen fallback
       └─ exact subject/provenance/Action refs
```

No Epi-specific CMS is introduced. HTML remains capable of primary authorship; derived pages retain sources; page refinement and source Return remain separate operations.

## 10. SharedField / Explore

SharedField receives an explicit Projection of an Expression or WorldPresentation, never ambient private runtime state.

A projected Expression may be served live when the target has an accepted renderer, or through image/video/HTML fallback. Source/subject identities, audience policy and provenance remain inspectable. A recipient may encounter, fork or contribute according to the SharedField contract without receiving another person's protected Nara state or Agent authority.

This turns Explore into a field of presented worlds rather than a social feed: a Contribution may be a living presentation of an actual experiment, concept, work, Agent or encounter.

## 11. Learning and refinement

The Expression Field can accumulate useful evidence about how people and Agents compose and inhabit it without silently becoming a self-modifying preference engine.

Retain as attributable evidence where authorised:

- human-created Expressions and scene structures;
- parameter/automation choices and later revisions;
- successful/failed Agent composition Methods;
- source/knowledge routes actually used;
- human corrections, acceptance, rejection and returned understanding;
- performance/resource evidence.

AIKit praxis, T/T′ consumption and recognised Methods may learn from that evidence under their existing laws. The engine does not infer truth, personality or therapeutic effect from aesthetic preference or visual coherence.

## 12. Non-negotiable ownership laws

```text
Expression != canonical subject
Expression entity != Agent/Wiki/M coordinate identity
Expression relation != WikiEdge/Contribution/KnowledgeRoute by appearance
renderer != M′ instrument
particle movement != evidence of Agent action
selection != Action
visible != disclosed to Agent
bound != authorised
live personal state != portable Expression
Expression save != source mutation
Expression projection != public without audience policy
WorldPresentation != Expression
Being/Thing presentation role != native identity class
```

The Expression Field succeeds when technology feels alive because the actual world is operable through a joyful material medium—not because presentation has swallowed the world it represents.
