# Space / Explore — a clear entrance and a world worth entering

**Version 2.** Preserve the existing Surface/travel system and native field owners. This is a targeted interaction pass, not another social feed, library or world database.

## 1. Recurring job

Choose the field to enter, find a work/world, open its actual presentation and come back without losing local work. The unbound experience gives a next act; the live experience gives the space to its material.

## 2. Unbound: one message, one action, one disclosure

Place the cluster at the centre of the available content lane, slightly above its vertical midpoint; maximum about 360 px wide, 12 px between the sentence and action. No surrounding error card, red border or unavailable pill.

```text
                 No field is connected.
                    [Choose field]
                       Details v
```

Details is collapsed and uses the actual redacted technical reason, not rewritten invented diagnosis. Choose field opens the real admitted target picker/configuration operation. Opening is navigation; only an acknowledged owner bind establishes connection.

Picker: actual target name first, useful location second, selected check; search only when useful for actual target discovery. Click/Enter selects, the explicit **Connect** confirms the chosen real target where supported. Escape cancels and restores focus to Choose field. A typed address is not connection success; never store a token in renderer state/localStorage.

If only a real configuration navigation route exists, call the button **Set up a field**, not Choose field/Connect with a fake binding. Put the one missing owner/path obligation in the invoked setup. Record full bind as pending, but do not leave the page as an env-variable sentence.

## 3. Live: search, identity, material

```text
[back] <actual field title> v       <presence marks>  [ ... ]
[search icon] Search worlds and work

<actual selected world/page/Expression owns the body>

<contextual source/relations control when summoned>
```

One compact title strip; no duplicated World/Field/Status headers. Keep real back/forward and query/reading history. Search results lead with actual names and one useful subject/type line; keyboard arrows select, Enter opens, Escape dismisses suggestions without clearing the query. An explicit Clear search control clears it. The query is not submitted on mere blur if the existing interaction expects Enter; preserve the current working contract and test it.

Selecting a result enters its actual page/Expression, not a metadata grid. Source and relations are contextual controls using existing auxiliary depth. A held reading does not change because another result arrived.

Presence uses a compact group of real avatar/dot marks. At most three visible marks plus a truthful overflow count if the owner supplies that coverage; otherwise show only known identities without inventing a global count. Activating opens the real participant detail. Do not make presence a permanent right-column roster. A participant click does not replace the person's accompanying agent.

Watch/Contribute/Follow/Share use a single appropriate primary action on the actual subject, with secondary actions in `…`. Unsupported actions are omitted; a deliberate blocked workflow explains its owner obligation once. Unfollow remains plainly reachable while following. Following never surrenders local tabs, draft or unrelated camera state.

## 4. States and exact copy

| State | Response |
|---|---|
| Unbound | **No field is connected.** + real **Choose field** or truthful interim **Set up a field** + collapsed **Details** |
| Connecting | Local pending in the invoked control; cancel only if real supported cancellation exists |
| Live | Actual title/search/material/presence; no platform statistics or empty tables |
| Working | Actual collaborator indication on the affected object, not a pasted session console |
| Needs-you | Exact invitation/contribution/request opens in existing detail; same native attention item |
| Error | **This field couldn’t be reached.** + **Retry** and details; retain permitted navigation context |
| Refused | **You don’t have access to this field.**; request-access control only if supported |
| Successful empty | **Nothing is shared here yet.** once |
| Search empty | **No results for “{query}”.** + **Clear search** |
| Stale/revoked | Preserve only permitted references/reading; remove newly unauthorized payloads, never fake liveness |

Other controls: **Search worlds and work**, **Back**, **Source**, **Relations**, **Watch**, **Watching**, **Follow**, **Unfollow**. Real subject names remain. Details do not disclose credentials/private endpoint parameters.

## 5. Subtraction list

Remove the full-page env-var diagnosis; duplicate unavailable pill/banner/footer; blank Worlds/Beings/Fields tables; permanent participant/configuration panels; always-disabled Watch/Join buttons; decorative fake relations; auto-replaced personal agent; any duplicate inbox queue. Keep genuine field-binding/travel routes and exact source/projection/authority distinctions.
