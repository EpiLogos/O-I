## 0. Governing relation

```text
OBJECTIVE INTERNALITY
        ↓
O:I CORE ONTOLOGY / PRIMITIVE FIELD
        ↓
S parent / transversal O:I field
        +
S0–S5 product positions
        ×
one QL-determined constitutional sixfold
```

The important correction is:

> **QL determines at every level relative to that level.**

The six constitutional families are therefore not a non-QL taxonomy laid across QL. They are themselves the **QL 0–5 determination of the primitive field at this constitutional level**, and any row, cell, primitive, WikiFrame, Context Frame or other sufficiently whole subject may recursively receive its own local 0–5 determination.

## 1. Constitutional sixfold

| QL | Constitutional family | QL function at this level | Meaning here |
|---:|---|---|---|
| **0** | **Identity / Centre** | implicit ground · source · referential centre · potential | The identity/centre from which this local field proceeds. |
| **1** | **Form / Artifact** | material/content determination · manifest **what** | The determinate thing/content/artifact that is present. |
| **2** | **Potency / Praxis** | efficient cause · **how** · power in operation | The capability/method/action by which transformation is actuated. |
| **3** | **Transformation / Trajectory** | formal mediation · relation · pattern of becoming | The relation or mediation connecting and transforming determinate forms. |
| **4** | **Embodiment / Actuality** | contextual arena · Context Frame · situated application | The encompassing context/life-world/material situation in which the relation becomes actual. |
| **5** | **Evidence / Continuity** | quintessence · synthesis · Return · recursive continuity | The returned difference/evidence/memory/Recognition retained into subsequent ground. |

### Critical terminology note

`Form / Artifact` at **#1** means **formed or manifest actuality: the WHAT**.

It does **not** mean QL's **formal cause**, which remains **#3**.

That distinction is exactly why the earlier ordering failed.

The local relation is:

```text
#0 identity / implicit centre
        ↓
#1 determinate manifest form / artifact
        ↓
#2 potency / praxis acting upon or through form
        ↓
#3 relation / mediation / transformation among forms
        ↓
#4 contextual embodiment / actuality of the whole relation
        ↓
#5 returned evidence / continuity / synthesis
        ↺
#0 renewed ground
```

## 4. Recursive law

The matrix is one QL determination of the O:I primitive field.

It does not terminate QL recursion.

For any sufficiently whole subject:

```text
subject
  ├─ .0 identity / ground
  ├─ .1 manifest form / what
  ├─ .2 potency / praxis / how
  ├─ .3 mediation / transformation relation
  ├─ .4 contextual embodiment / actuality
  └─ .5 Return / evidence / continuity
```

Examples:

```text
Capability
    can itself be differentiated 0–5

WikiFrame
    can itself be differentiated 0–5

Project
    can itself be differentiated 0–5

SharedField
    can itself be differentiated 0–5

a matrix cell
    can itself be differentiated 0–5 where materially useful
```

The parent matrix does not replace these internal forms.

## 5. Matrix addressing

Do **not** use `S2.2` as the canonical matrix address because dot notation is already meaningful for recursive QL addressing.

Use:

```text
S/P0 ... S/P5

S0/P0 ... S0/P5
...
S5/P0 ... S5/P5
```

Machine form should retain separate fields:

```json
{
  "row": "S2",
  "ql_position": 2
}
```

This keeps product-position addressing distinct from recursive QL path notation.

## 6. Primitive registers

Retain the original Factory distinction, generalised to O:I:

```text
A — experienced / product primitive
B — resolution / execution primitive
C — substrate / trust primitive
S — transversal / parent primitive
```

Registers do not determine whether something is ontologically fundamental.

Semantic identity and implementation form remain separate facts.

`CommonReferent` remains the standing example:

```text
semantic role:
    stable referential pole over attributable bindings/forms

possible implementation form:
    derived / rebuildable mediation read model
```

Both facts belong in the registry.

## 8. Parent S

Use `S` for relations whose meaning is natively whole-level or cross-product.

Current strong candidates include:

```text
World

Participant
```

A product may implement or project part of one of these relations without thereby owning the whole semantic relation.

## 9. Wiki / Knowledge ontology

The live AIKit Wiki implementation already has the generic object floor:

```text

WikiFrame

```

with explicit identity, revision and provenance.

The wider knowledge field is:

```text
SemanticWiki
SourcePool
CodeIndex
ProjectMap
      ↓ federation
KnowledgeApplication
      ↓
search / open / explain / route / Context projection
```

This is **federation, not a universal graph**.

Living Knowledge adds revision-sensitive relations:

```text
Source revision
    ↓
KnowledgeChangeHorizon
    ↓
explicit source/resource basis dependencies
    ↓
KnowledgeImpact / freshness
    ↓
affected knowledge / WikiReading
    ↓
integration / contemplation / Return
```

Do not collapse these with arbitrary semantic Wiki edges.

Neighbouring distinctions remain:

```text
Flow             != WikiSpace
WikiFrame        != SharedField
WikiReading      != authored source
KnowledgeRoute   != truth
Projection       != Contribution
CommonReferent   != source object
Encounter        != belief
provider identity != Wiki semantic identity
```

The documentation harmonisation work should make these relations first-class and navigable.

## 12. QL-MEF consequence

This `S + S0–S5 × P0–P5` field does not require a second QL substrate.

It should be represented using the existing six-position, recursive, Context-Frame and shape machinery.

The key requirement is that QL-MEF and Wiki tooling can represent:

```text
one whole
    ↓ sixfold determination
0 / 1 / 2 / 3 / 4 / 5
    ↓ recursive internalisation when useful
x.0 ... x.5
```

and can carry the O:I row coordinate as the subject/domain position without confusing it with the local QL path.
