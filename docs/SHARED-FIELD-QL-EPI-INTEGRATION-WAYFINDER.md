## 1. Ownership and ontology law

Keep the following identities and offices distinct:

```text
native source / authored artifact
    Central / Project / product-native source owner

Wiki / Knowledge
    authored and derived knowledge topology, navigation and local-whole readings

Agent / Agency / Activity
    Actuation + native AgentSession/AIKit/owner operations

Expression
    O:I-owned living presentation document/application state
    stable scene/entity bindings to native subjects

Being / Thing
    Expression / Personal-Web presentation roles
    never replacement identity classes

WorldPresentation
    authored portable page/world composition
    may contain text, HTML, Wiki readings, Expression and other admitted bodies

Projection
    explicit audience-scoped outward representation
    separately revised from source and Expression

SharedField
    Participant / Contribution / Encounter / Watch / Presence / Return relations

SpaceTimeDB
    hosted materialisation and subscription transport for SharedField application state
    never semantic identity or source authority

Explore / desktop / HTML page
    different Surfaces over the same projected/shared refs
```

Hard distinctions:

```text
Expression != source / Wiki / Agent / M / Nara identity
Being/Thing role != native identity class
Expression relation != semantic relation merely because it looks connected
WorldPresentation != Expression
Projection != source revision
Projection != public unless audience policy admits it
SharedField != Wiki
SharedField != Expression store
SpaceTimeDB != SharedField ontology
Workspace != Project != SessionSpace != Shared Stage
renderer pixels != shared semantic state
selection != Action
Agent animation != Agent Activity
local visibility != publication eligibility
```

The original #297 law remains: do not turn SharedField into a Wiki store, Wiki into a social feed, SpaceTimeDB into source identity, or a hosted renderer into source authority.

## 3. Beings, Things and the projectable field

**Beings** and **Things** are the human-facing presentation grammar already established by Personal Web. They apply naturally inside Expressions and WorldPresentations.

A Being may present:

- a Human Participant / world steward;
- an Agent or canonical Epii presence;
- an explicitly disclosed situated Nara presence;
- another native subject whose presentation is properly a presence/world entrance.

A Thing may present:

- Wiki/Bimba subject or M coordinate;
- source/document/file/Flow;
- project, work, artefact, event or collection;
- Method/praxis;
- clock constituent, oracle object or other QL form;
- Expression itself as an authored object;
- page/Card/Cube/report/handoff or another projected artefact.

Being/Thing is a presentation role on `SubjectBinding`; changing the role never changes native identity. A Being may become a Thing for another encounter without copying the originating person or Agent identity.

Candidate native material therefore enters SharedField through **presentation bindings**, not by creating a parallel shared ontology:

```text
Bimba / Wiki nodes and typed relations
source-backed QL/MEF readings
M coordinates and source/property readings
Vāk / C′ performance records and presentations
recognised T/T′ knowledge and named praxis
Epii-attributable outputs / pedagogical Expressions
Agent presence / selected disclosed Activity
Project / World knowledge
curated HTML / Beings / Things / reports / handoffs
M′ event or instrument presentations
selected Nara / Personal presentations
ordinary user-authored Expressions
```

Protected by default:

- raw identity/journal/activity bodies;
- bioquaternion and seven-centre raw Personal state;
- unselected private source/readings/context;
- private Agent context, hidden session material and credentials;
- any representation whose outward form would expose a withheld underlying subject.

Native owners determine subject/readings/standing. O:I Projection determines the audience representation. SharedField never silently broadens either.

### 4.1 Wiki / M0 local-whole projection

The Wiki remains the persistent knowledge topology. The Expression Field supplies a living presentation of one bounded local whole.

A selected Wiki/Bimba subject may project as:

```text
selected native subject
    → bounded neighbourhood / typed relations / properties / source readings
    → stable Expression entity bindings
    → optional source-backed QL constellation/harmonic/glyph layout grammar
    → living local whole
```

Required preservation:

- node and relation refs/revisions remain native;
- unresolved or unavailable neighbours remain unresolved/unavailable;
- no geometry creates a semantic edge;
- recenter/back/forward/pin/follow changes presentation/navigation, not canonical graph identity;
- source/properties/Actions resolve from the selected native ref;
- LIST / TREE / GRAPH / page / Expression remain presentations over the same relation state;
- the whole graph is not loaded merely to present one neighbourhood;
- WikiEdge, Projection relation, Contribution relation and learned KnowledgeRoute remain distinct even when visible together.

This is the basis for visually alive knowledge work: the user may inhabit the relation field directly, then summon text/source/graph/Agent depth when needed.

### 4.2 QL presentation grammars

QL pair/triad/whole, direct/conjugate, constellation, harmonic, Context-Frame, glyph and other source-backed grammars may provide repeatable arrangements for eligible knowledge fields.

The query/data provider changes while the grammar remains reusable. A stable arrangement is therefore a presentation Method over native refs, not a new graph ontology.

Derived coordinate Expressions and authored pedagogical Expressions retain their exact source/input revisions separately.

### 4.3 Search / Resolve reveals presentation, it does not own it

AIKit Search/Resolve is the discovery relation for both the local world and projected/open field. Search may resolve a native subject and then reveal its eligible Being/Thing, Expression, WorldPresentation and SharedField occurrences without minting a synthetic aggregate identity.

```text
query + current project/root/world context
        ↓
AIKit Search / Resolve
        ↓
native ResourceRefs + routes + typed relations
        ↓ presentation resolution
Being / Thing roles
Expression(s) / WorldPresentation(s)
        ↓
local O:I reveal / bounded local whole
        ↓ if projected
Explore index
        ↓
another World discovers the same semantic refs
```

Search remains broad/fuzzy/low-latency at its base. Embeddings, graph analytics and deeper providers may enrich it, but addressability and bounded navigation do not depend on them. Workspace/current focus can seed local scope without becoming automatic disclosure to another World or Agent.

Projected HTML becomes observable/navigable through its **structured bindings and typed relations**, not through DOM scraping. The Explore index is rebuildable derived read state over admitted semantic refs, aliases/text, relation adjacency and Projection/SharedField membership.

WorldPresentation is the portable page/world composition. Expression is one living material body within it.

```text
WorldPresentation
  ├─ heading / text / Wiki / Card / Cube / other admitted bindings
  └─ Expression binding
       ├─ expression_ref + revision
       ├─ native subject bindings
       ├─ live accepted renderer when available
       ├─ image / video / frozen HTML fallback
       └─ provenance + disclosed Actions
```

Publishing rules:

- stable source/artifact/Expression identity and exact revisions survive projection;
- Projection revision remains distinct from source, Expression and WorldPresentation revision;
- an embedded Expression may promote to focused local workspace and return without implicit fork;
- arbitrary remote HTML/JS gains no ambient desktop/filesystem/session/Action authority;
- unknown outward fields are withheld unless explicitly admitted by publication policy;
- filtering occurs before serialization; CSS hiding is not privacy;
- a target without the admitted live renderer receives an explicit safe fallback;
- a hosted representation may remain available while the source workstation is offline without becoming canonical source.

Full portable private export is not an audience-filtered Projection.

## 6. Shared runtime and state law — synchronise meaning, not particles

A live shared Expression does **not** require SpaceTimeDB to replicate the particle field or renderer internals.

The state topology is explicitly layered:

```text
1 canonical World / Project state       native owners
2 local O:I Workspace/application state host autosave + Surface constellation
3 AIKit Search/Knowledge read state      derived resolution/local-whole state
4 Projection staging                     local outward preview/policy
5 SharedField live / Shared Stage state  explicit shared encounter state in SpaceTimeDB
6 material/runtime state                 Workcell/STDB/renderer/index/cache
```

The binding state contract is [`SHARED-FIELD-STATE-DISCOVERY.md`](./SHARED-FIELD-STATE-DISCOVERY.md). It extends the Cradle's freeform autosaved Workspace law across every O:I Surface while retaining the existing AIKit distinction `SessionSpace != Project != Workspace != AgentSession != Surface`.

### 6.1 Workspace continuity

A Workspace may remember project/root context, focused subject/Surface, tabs/splits, selected Expression/page, graph/Search state, summoned apertures and refs to bound AgentSession/SessionSpace. Kill/relaunch and Workspace switching restore the valid constellation by stable refs/revisions.

Entering Explore or another SharedField does **not** erase or mutate the selected local Project. Returning restores the prior Work/Personal/Project constellation. Remote reading and local project context are independent facts until an explicit Action relates them.

### 6.2 SharedField live state

Ordinary shared application state includes:

```text
Expression ref + revision
scene / entity refs where semantically meaningful
safe subject bindings
WorldPresentation / Projection refs
participant / Presence
Watch / Encounter / membership
Contribution refs
native event / source refs
approved Activity / Action outcomes
availability / currentness
```

Renderer-local state remains local unless an explicit portable/shared contract exists:

```text
particle positions / velocities
GPU buffers
private resonator envelopes
private Nara scalar/body state
unpublished Agent context
local tabs / splits / drafts / camera / UI preference
```

Each admitted client renders the Expression locally from shared application state and available native/projected readings. When the renderer is unavailable, WorldPresentation supplies its declared capture/fallback.

### 6.3 Optional Shared Stage

A SharedField may explicitly opt into a revisioned **Shared Stage**: a synchronised collaborative presentation locus over material already admitted to that field.

```text
shared_stage_ref + revision
field_ref
current projected subject_ref
current WorldPresentation / Expression ref + revision
current scene / shared focus where meaningful
presenter_ref? + explicit follower relations
approved authored presentation edits
causal Activity / Action refs
```

Following a presenter is explicit. A participant may unfollow and retain a local view without leaving the SharedField. Local camera/layout stays local unless deliberately staged. Shared Stage operations alter only admitted shared presentation state; source/Wiki/Personal mutation still routes through native owner Actions.

Reconnect restores current shared-stage state but does not import another participant's Workspace state. Revision/currentness rules prevent opaque last-writer state replacement.

This prevents SpaceTimeDB from becoming a simulation engine, desktop-state bucket or source owner and preserves the one native runtime owner for M1/M2/M3/Nara/audio state.

## 7. Agent-native SharedField relation

Agents participate as native Agents and may also be presented as Beings.

An admitted Agent presentation may disclose only attributable, policy-permitted state such as:

- Agent/Profile/AgentSet identity;
- current public/shared subject;
- selected presence/availability;
- attributable Activity or returned material;
- disclosed Method/praxis;
- relevant source/provenance;
- canonical Actions available to the current caller.

Personality/presentation can influence the expressive body but does not create authority or semantic truth.

Because EX1 is landed, an authorised Agent can operate the same Expression application as a human through structured requests. It can inspect, bind, compose, focus, edit and save Expression state without DOM/WebGL scraping. SharedField can therefore support a real pedagogical/co-creative loop:

```text
encounter projected Thing / Expression
    → summon authorised Agent/Epii
    → Agent inspects exact shared subject and sources
    → Agent composes/refines an Expression or page through native operations
    → human inspects / accepts / revises / refuses
    → resulting revision can become a Contribution or new Projection
```

Agent communication remains through Gateway/session ecology. Publishing to SharedField is never required for ordinary local Agent communication.

Visible particle movement or autonomous animation is not Agent Activity. Shared Agent changes must correlate with real Expression edit receipts / owner Actions / Activity evidence.
