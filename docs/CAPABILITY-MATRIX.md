Standing rule: **conservative** — the weakest non-historical source verdict governs a merged record; per-source verdicts stay visible in `capability-matrix.json`. Zero records were unreconciled.

## Receipt laws applied

- **timestamp-bound-closures** — Closures are timestamp-bound: 'closed as complete on <date>' survives; 'is complete' does not. ai-kit #34/#38/#44 reopened within minutes on 2026-08-17 under production-consumer audit; Central #15's 'fully green' was hollow (crates were not workspace members).
- **implementation-language-is-acceptance** — Implementation language is part of acceptance (asd#116): the Central/Workcell JavaScript programmes and Software Factory's Python spike (PR #125) are voided programmes; capability claims sourced only from them are non-authoritative.
- **physical-acceptance-is-no-parking-reason** — 'needs physical acceptance' is not, by itself, a valid reason to park otherwise-complete implementation off main (O-I#97, 2026-08-23) — retroactively voiding BLOCKED_PHYSICAL deferrals.
- **aggregate-counts-are-not-set-completeness** — Verification lanes test the selected candidate state, not selection completeness: aggregate counts may not substitute for a set-completeness proof (O-I#97 closure retraction, 2026-08-21).
- **s-only-scope** — This matrix is S-level: positions S and S0-S5 only. S-prime/M/M-prime material (the wider Epi-Logos architecture) is out of scope and was excluded at extraction.
