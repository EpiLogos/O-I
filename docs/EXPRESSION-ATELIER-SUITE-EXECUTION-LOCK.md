# I. Fixed conceptual laws

## 1. Expression is a world presentation, not a semantic store

An Expression can bind and inhabit source objects without becoming their owner.

It may contain or present:

- live particle compositions;
- text/Markdown/spans;
- glyph/SVG/ASCII;
- images/media/diagrams;
- generic file Things;
- Wiki bounded local wholes;
- HTML / WorldPresentation / native Surfaces;
- Agents/Beings;
- another Expression/Edition under recursion/resource limits.

Unsupported formats remain valid Things with explicit fallback/native open Actions. Do not invent a fake renderer to claim universal support.

## 2. Front / verso are two presentations over one identity

The living front and structured verso/back remain the same Expression identity.

```text
front
  material expressive body

verso
  source · provenance · page · files · relations · Actions · explanation
```

Opening source or page inline/beside/full/detached must preserve Expression/scene/selection identity and permit Return/re-dock.

## 3. Profile is presentation grammar, not meaning

```text
ExpressionProfile = reusable material/presentation grammar
subject Reading    = native meaning/current truth
Expression         = instantiated presentation over bound truth
```

Profiles may carry material defaults, form vocabulary, colour, physics, transition, camera, text and fallback grammar. They do not decide source semantics.

## 4. Library is an index/collection, not the world boundary

Expressions are addressable Things. They may be found through Wiki, files, pages, Projects, Personal Web, SharedField or another Expression.

The human Library remains valuable but is not the sole owner of identity.

The Point-Cloud production repository additionally holds the **bounded artifact/craft Library** for the works produced through its Atelier.

# II. Graph = Expression field

## 5. One canonical relation state, several views

For a Wiki/Bimba/source-backed subject:

```text
canonical subject / coordinate
      ↓
bounded local whole
  exact node refs
  exact typed relation refs
  readings/properties/source standing
  unresolved/unavailable relations
      ↓
ExpressionGraphBinding
      ↓
material/spatial/textual/glyphic relation presentation
```

`LIST`, `TREE`, conventional `GRAPH`, page/minigraph and `EXPRESSION` are alternate presentations over the same attributable relation state where their source scope is the same.

Changing graph location changes the active Expression subject/state. Focusing a bound Expression entity/relation updates the same canonical selection/deictic refs.

The Expression may therefore be the resting graph experience; a conventional graph remains a summonable optic/aperture.

## 6. Constellations are layout grammar

QL constellation/harmonic structures may determine placement, grouping, symmetry, emphasis and transition **over relations already supplied by the native source**.

They never:

- create a semantic edge from adjacency;
- promote visual resemblance into canonical relation truth;
- erase missing/disputed relation standing to complete a shape;
- replace native relation IDs with renderer-local edges.

Partial constellations are legitimate.

# III. Scene carriers, portals and form vocabulary

## 7. Any native Thing may become a scene subject

A scene can be a live field, file, page, image, glyph, Wiki local whole, Agent presence or mixed composition.

Scene triggers are declarative references to existing operations:

```text
scene/entity/text cue
→ source_ref / subject_ref
→ Expression operation | SurfacePortal | focus/navigation | native ActionRef
→ native Surface
→ Return/re-dock
```

They are not arbitrary renderer scripts.

## 8. Visual forms arise through production

O:I owns the generic reusable asset-ref/index contract. It does **not** prescribe an advance corpus iconography.

The production law is:

```text
content need
→ form candidate discovered/created/adapted
→ actual live Expression occurrence
→ witness/critique
→ accepted occurrence
→ reusable asset/form index
```

The index must support:

```text
subject / motif / coordinate
→ admitted visual variants
→ every Expression/Scene occurrence

asset/form
→ source/provenance/rights
→ subjects/roles it may represent
→ every occurrence
```

One image is never the meaning of a Being or Thing.
