# shared-field/dist-client

Generated by `shared-field/spacetimedb/build-client.mjs` (run by
`desktop/cradle/package-bundle.sh`): the self-contained SharedField client an
installed desktop carries as its Tauri resource `shared-field/`.

This directory is tracked only so the resource path exists for every build.
A build made without running the builder carries this README alone; the
native shell then binds no bundled client (it requires `field-client.sh`)
and a development kernel falls back to the checkout's own `field.sh`.
