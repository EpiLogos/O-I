# Work

This directory is the personal home for Projects.

A Project can be new, cloned, or adopted from an existing local path. Moving source into this tree does not create a new Project identity by itself.

A Project can carry a `ProjectCentral/` — the same human-source/Agent-Wiki relation as Control, repeated at Project scope. See `templates/Project/` for the default Project scaffold.

Central owns project placement and migration behaviour.
