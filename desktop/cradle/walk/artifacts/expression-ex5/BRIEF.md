# EX5 — Personal Web / HTML / WorldPresentation

Relation: O:I makes one native Expression usable as an ordinary page body
through WorldPresentation because the client explicitly admits the accepted
renderer or selects a declared safe fallback.

## Design law

- WorldPresentation composes the page; Expression supplies one living body.
- Expression is not its source or subject; focus is presentation state, not a fork.
- Use the accepted live renderer or explicit image, video or frozen HTML fallback.
- DOM and pixels are never semantic addresses. Preserve refs, revisions,
  provenance, disclosed Actions and native authority.
- Remote HTML receives no filesystem, session or Action authority.
- Page editing, Expression state, capture, source Return and publication remain
  separate operations.

## Files and operations

- `shared-field/expression-presentation.mjs`: bounded renderer admission contract.
- `site/src/explore/presentation-components.tsx`: portable registry renderer.
- `desktop/cradle/src/personal/page-expression.mjs`: Personal Web binding adapter.
- `desktop/cradle/src/personal/PageExpression.tsx`: live page host, focus and capture.
- `desktop/cradle/src/material/MaterialSurface.tsx`: exact owner file revision admission.
- Read the page through Central, inspect the native Expression, compare exact
  revisions and subject/source bindings, host the one stage canvas, move that
  canvas into focus and back, invoke the engine capture, then refuse stale state.

## Walk

Beings page → live Expression → focused workspace → return → engine capture →
native revision advance/refusal → captured fallback → exact live re-entry.

Metrics: exact page/expression/subject identity, stable canvas identity, PNG
dimensions and sampled colour count, stale refusal, fallback state and re-entry.
