# EX5 Expression page acceptance

The kernel-backed running desktop opened a real temporary Central Beings HTML
file, read its `ql-doc` at the owner's exact file revision, inspected a native
Expression at the page's pinned revision and rendered it through the one Global
Expression Stage.

The walk moved the same canvas into focused presentation and returned it to the
same page. The existing engine capture produced a 978×280 PNG with 39 distinct
sampled colours. The capture stayed page-local until the walk explicitly wrote
it into its temporary fixture as a fallback asset; the product did not claim a
capture persistence or publication operation.

An Agent-attributed native Expression edit advanced the revision. The page
released the stage and disabled focus/capture rather than showing old pixels as
current. A newly read page revision first rendered the explicit image fallback,
then re-entered the same `expression:page-ada` identity when live availability
was restored.
