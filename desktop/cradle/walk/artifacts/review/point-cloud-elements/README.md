Open http://127.0.0.1:4288/desktop/cradle/walk/artifacts/review/point-cloud-elements/ . Dedicated server runs from the O-I repository root on port 4288.

Revision 6 (2026-09-08) is honed to the owner's kept list: the four elemental directions (fire, water, air, earth), arrival, presence, idle, listening and searching. Interactions are one kept example (panel resize) plus two raw demonstrations of the expression system underneath (drag-to-direct with hold, and anchored edge wisps with delay and chain), all answered by one full-window overlay. One agent-expression strip morphs a single field between the kept forms. All eleven canvases are actual Canvas 2D dot compositions; preview controls change running behavior. Shared desktop palette and exact shared O:I masked-dot mark are consumed directly. The logo appears only in the explicit fullscreen initial-load preview. This is an isolated visual showcase, not a production loading flow or an operation-status claim.

Interaction dynamics are bounded wisps on one fixed full-window overlay canvas (`#expression`, pointer-events none, page coordinates, scroll aware): `express(gesture, {rect|x,y})` pushes an emitter anchored to a component rect read on demand; the scheduler draws it around the component's edges and drops it when it expires. Revision 5 adds direction (`from`→`rect` travel or an explicit `dir`, with `lean`) and time (`delay`, `hold` until `release()`, `then` chaining) to the seam, and draws every dot from a soft circular sprite (~4 device px) so grain reads round rather than as pixel blocks; the header carries a `rev 6` stamp and the page is served no-store. Revision 6 mutes the ink: the canvas colour is the foreground mixed 42% toward the surface and the per-dot opacity ceiling is 0.34, so dense overlaps stay grey and never reach black. Thinking, holding, settling, relation and the earlier component-specific gestures (vapour, confirm, dismiss, release, open, close, wake, drop, save) are no longer shown; their drawers remain in the file as reserve vocabulary for W1.8. The component lands first by its own token transition; the wisp follows on `transitionend`. The overlay is verified pixel-clear when idle. Gestures are ignored under pause and reduced motion, and the emitter list is cleared whenever drawing is not allowed, so nothing accumulates. Theme buttons swap the root class between `oi-desktop`, `oi-surface-light` and `oi-surface-dark` from the shared tokens; the canvas ink is re-read from `--oi-foreground` on each swap.

Motion uses one shared requestAnimationFrame scheduler, capped at approximately 30 drawing frames/second and pixel ratio 2. Only intersecting fields draw. Pause, reduced motion, document hiding and fullscreen preview stop the canvas scheduler. Observers and listeners are released on pagehide. There are no particle arrays that grow across interactions, retained timers or dependencies. The fullscreen preview traps focus and makes the background inert until Escape or Return closes it.

Narrow viewport renders only intersecting fields. Screenshots show actual output at 2×. These are functional animation lifecycle checks, not a native resource/performance acceptance claim.

Design intent (revision 6, 2026-09-08): all fields use a finer grain (dot radius ~0.3–0.42 CSS px at 2×, 800–1200 points per field, thinned in revision 4), with each object roughly half its previous footprint, so the fields read closer to a render resolving than an illustration. Fire is two counter-turning helical arms with a leaning axis that breaks into turbulence at the tip; water is a lateral stream bending around two drifting eddies; air remains open and elliptical with a soft centre; earth is now a volumetric cube of eight strata at alternating densities, drawn back-to-front with slight rotation so the cube shape reads at a glance.

The six proposed states are candidates, not decisions: thinking (inward spiral, agent reasoning before a reply), listening (shallow bowl catching drops, input capture), holding (ring with a still core, something kept but not acted on), searching (a soft band sweeping a faint lattice, index and lookup), settling (grains falling and stacking, sync/save landing), waiting (a low horizon with a slow breath, blocked on the operator). Interaction dynamics (revision 6): panel resize is the one kept interaction, for its subtlety. The two raw demonstrations show the system itself: press, drag and release gives a wisp an origin, a direction and a reach from the drag; holding still before release sustains it until let go; the anchored rect lets a wisp go from any edge in that direction, and Chain runs all four with delays on the shared clock.
