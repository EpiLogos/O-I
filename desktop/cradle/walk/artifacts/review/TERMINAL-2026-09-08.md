# Terminal implementation evidence — 2026-09-08

The desktop terminal is a real local pseudoterminal owned by the Tauri host. A
terminal surface starts the user's login shell in the selected absolute working
directory, forwards input bytes, streams output by sequence cursor, applies PTY
resizes, and sends control characters such as Ctrl-C to the foreground process.

## Lifetime and movement

Each session is keyed by its kernel surface id and remains alive while its view
moves between the workspace and a detached native window. Every attachment gets
a new lease; input, resize, polling, and checkpoints from the previous view are
then refused. Closing the surface removes the session, wakes a blocked reader,
terminates a live child, and waits for it. A shell that exits itself is also
waited for. Reconciliation processes every removed session and retains any row
whose close fails so cleanup can be retried.

Sessions belong to the running desktop host. Quitting the app ends them; process
and screen persistence across an app restart is not implemented. Within one app
run, a checkpoint compacts acknowledged output and carries the rendered screen,
revision cursor, and working directory into the next attachment.

## Output bound

Unread PTY output is bounded to 1 MiB. The reader applies backpressure at that
boundary instead of dropping bytes. A valid checkpoint drains acknowledged
bytes and wakes the reader. Close also wakes it, so a full buffer cannot prevent
process shutdown.

## Real test evidence

`cargo test terminal::tests -- --nocapture` passed five integration tests on
the actual platform PTY and login shell. No shell, child process, reader, writer,
or filesystem operation is mocked.

- Input/output executes a shell command and observes its emitted marker.
- Resize changes the real `stty size` reading to 37 rows by 101 columns.
- Ctrl-C interrupts a running `sleep`; the command after it does not execute.
- Checkpoint and reattach preserve the screen snapshot and sequence cursor,
  reject the stale lease, and continue using the same shell.
- A 1.2 MB producer demonstrates the 1 MiB bound and resumes after checkpoint.
- Natural shell exit is reaped; explicit close and repeated close also finish
  with the child reaped.

`cargo check` and `git diff --check` also passed after the implementation.

The final lifecycle regression pass also covers descriptor-closed sleeping shells and foreground-child hangup. The EOF reaper polls without holding the I/O mutex between checks; explicit close completes in under two seconds in both real PTY cases.
