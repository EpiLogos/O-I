# L3 — Devices brought past the widget guides

Label: wayfinder:task (execution lane)
Claimed-by: —
Blocked-by: C3

Zones: existing device faces (morph, colour, force, settings, native.agent)
and new faces as they land.

## Question

Bring every landed device up to and beyond the widget guides — no cut
corners, and no ceiling either. Close the C3 gap lists (they are floors:
states, tooltips, keyboard, empty and refusing states), then improve: the
real feature must function and look **better** than the mockup drew it.
Plug real capabilities into the mockups' waiting component forms (agent
device, skillset rack, context-world, agentset) wherever a native owner
exists; where one does not, the form stays with an honest waiting state —
never a fake.

## Evidence / acceptance

Per-device guide review recorded: gaps closed, improvements noted — and
improvements are written back into `WIDGET-GUIDE.md` so the guide tracks
the best landed state, not the first drawing. Computer-use side-by-side
against the mockups showing where the implementation exceeds them. Aperture
law intact throughout (every action names its boundary_op; a UI flag is
never evidence).
