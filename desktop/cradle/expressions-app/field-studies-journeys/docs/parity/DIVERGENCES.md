## Retained limits, not hidden omissions

The native entity model supports ten formation allocations and eight pins. The
interface rejects over-capacity documents instead of allowing native truncation.
The registry retains `autoMorphDuration`, but the authoritative entity runtime no
longer consumes it; sequence timing and the shared phase clock are the operative
controls. Native `cymatics.sweepSpeed` is **not** disabled: it remains the fallback
when an explicit sweep glide time is absent.

Preview-only damping/flow/warp/thickness/lattice macros without a justified native
law are disclosed, not wired to a plausible neighbouring coefficient. The source
contains no finished runtime checkpoint, arbitrary physical seek, input replay,
offline deterministic clip renderer, audio capture or seamless-loop guarantee.
These are not converted into fake capabilities. Finite comparison matrices do not
prove every possible input, browser, GPU or frame sequence mathematically.
