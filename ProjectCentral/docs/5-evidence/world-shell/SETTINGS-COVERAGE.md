## Scope, value and timing semantics

Allowed scope menus preserve descriptor order; that order is not asserted as a universal inheritance hierarchy. Non-singular scopes require actual subjects. Native desired, declared, effective and active readings retain their identity, provenance and timing; local drafts are another axis. Native resolvers determine precedence. AIKit’s absent skill-set v2 axis stays unknown. Factory contributes no literal defaults for its three numeric settings; none is invented as native truth. Workcell declarations offer services to discovery and do not start them without demand. Formal policies and readiness facts stay read-only.

The existing effectiveChatDefault function is reused: held owner choice naming a configured provider, then the literal pi row, then first configured provider. Named sparse O:I settings profiles differ from AIKit composition profiles. Use profile stages validated LOCAL drafts for ordinary review. Saving/importing a profile applies no settings.

## Mapping legend and wiring status

R = readRegistry/readResolutions through the existing ConfigPlaneSource. P/A = plan(requests,basis), then apply the exact reviewed native PlanDocuments. Reset removes a native override; it is not discardDesired. Local validation preserves map/rows/record types, units/ranges and dependent choices. Native refusal, pending/failed acknowledgements, stale basis and owner/access changes retain drafts. A successful receipt clears only the matching submitted version and successful scope. Reading preflight is not atomic CAS.

The native/state owner has implemented src/native/configuration.ts::connectNativeSettings with reviewed_apply + owner_plan_passthrough qualification, current epoch guards and qualified native reset. The parent owns admission/binding via configureSettingsHost. This running frontend has no qualified settings adapter bound; live native persistence and the optional retained-operation bindings remain unverified. The development source census and scenarios never qualify admission, effective values or persistence.
